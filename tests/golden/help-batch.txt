usage: openswarm batch [-h] [--repo REPO] [--cards CARDS] [--hosts HOSTS]
                       [--per-host PER_HOST]
                       [--backend {codex,ocgo,deepseek,cursor,agy,pi,hermes,copilot}]
                       [--model MODEL] [--effort EFFORT] [--verify VERIFY]
                       [--budget-minutes BUDGET_MINUTES]
                       [--backends-file BACKENDS_FILE] [--verify-evalid]
                       [--evalid-bin EVALID_BIN] [--health-gate]
                       [--no-health-gate] [--skip-health-gate] [--base BASE]
                       [--scope {repo,host}] [--detach]
                       [--card-type CARD_TYPE] [--rework-of REWORK_OF]
                       [--paths PATHS [PATHS ...]]
                       [{status,plan}] [id]

positional arguments:
  {status,plan}
  id

options:
  -h, --help            show this help message and exit
  --repo REPO
  --cards CARDS
  --hosts HOSTS
  --per-host PER_HOST
  --backend {codex,ocgo,deepseek,cursor,agy,pi,hermes,copilot}
  --model MODEL
  --effort EFFORT
  --verify VERIFY
  --budget-minutes BUDGET_MINUTES
  --backends-file BACKENDS_FILE
                        custom backends config (JSON, M3 slice 1, #101);
                        defaults to $OPENSWARM_HOME/backends.json; passed
                        through to each run
  --verify-evalid       verify every card with evalid: replay the executor's
                        claimed test command in a clean clone via `xflow
                        audit` and record the claim-vs-replay verdict in the
                        ledger (M13 slice 1, #151); a card may instead declare
                        `verify-evalid: true` on its own line; requires
                        --verify; fails loudly when evalid is unavailable,
                        never falls back to plain verify
  --evalid-bin EVALID_BIN
                        evalid binary forwarded to each run: path to xflow, or
                        to a bin/xflow.js checkout (run via node); overrides
                        EVALID_BIN, xflow on PATH, and the sibling ../evalid
                        checkout on the executor host
  --health-gate         enable the pre-dispatch backend health gate for this
                        batch (M25, #202): probe each card's selected backend
                        before dispatch and refuse an unhealthy one (the card
                        is blocked, no exec attempt, never rerouted)
  --no-health-gate      disable the pre-dispatch backend health gate for this
                        batch even when routing.health_gate.enabled is true
  --skip-health-gate    bypass the health gate for this batch; the bypass is
                        recorded on each card's summary row (M25, #202)
  --base BASE
  --scope {repo,host}   task scope (repo by default; host for authorized host
                        operations)
  --detach
  --card-type CARD_TYPE
                        optional task card type from knowledge/card-types.yaml
  --rework-of REWORK_OF
                        run id this batch reworks
  --paths PATHS [PATHS ...]
                        path hints for matching applicable lessons
