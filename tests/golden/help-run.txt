usage: openswarm run [-h] [--type TYPE] [--difficulty DIFFICULTY]
                     [--context-tokens CONTEXT_TOKENS]
                     [--backend {codex,ocgo,deepseek,cursor,agy,gemini,pi,hermes,copilot,github-issue}]
                     [--model MODEL] [--effort EFFORT] [--card-type CARD_TYPE]
                     [--rework-of REWORK_OF] [--paths PATHS [PATHS ...]]
                     [--prompt PROMPT] [--task-file TASK_FILE] [--title TITLE]
                     [--backends-file BACKENDS_FILE] [--cwd CWD]
                     [--scope {repo,host}] [--base BASE] [--no-worktree]
                     [--verify-baseline] [--verify VERIFY] [--auto-rework [N]]
                     [--verify-evalid] [--evalid-bin EVALID_BIN]
                     [--keep-worktree] [--no-fallback]
                     [--budget-minutes BUDGET_MINUTES] [--detach] [--dry-run]
                     [--health-gate] [--no-health-gate] [--skip-health-gate]
                     [--read-only] [--executor EXECUTOR]

options:
  -h, --help            show this help message and exit
  --type TYPE           impl|refactor|debug|test|docs|mechanical|review|resear
                        ch|migration|format|rename
  --difficulty DIFFICULTY
                        1 (trivial) .. 5 (hardest)
  --context-tokens CONTEXT_TOKENS
                        approx context the executor must read
  --backend {codex,ocgo,deepseek,cursor,agy,gemini,pi,hermes,copilot,github-issue}
                        force a backend. cursor, agy (alias gemini) and pi are
                        opt-in and are not chosen unless named here or listed
                        in routing
  --model MODEL
  --effort EFFORT
  --card-type CARD_TYPE
                        optional task card type from knowledge/card-types.yaml
  --rework-of REWORK_OF
                        run id this task is reworking
  --paths PATHS [PATHS ...]
                        path hints for matching applicable lessons
  --prompt PROMPT
  --task-file TASK_FILE
  --title TITLE
  --backends-file BACKENDS_FILE
                        custom backends config (JSON, M3 slice 1, #101);
                        defaults to $OPENSWARM_HOME/backends.json
  --cwd CWD
  --scope {repo,host}   task scope (repo by default; host for authorized host
                        operations)
  --base BASE           base commit for an isolated worktree; defaults to HEAD
  --no-worktree
  --verify-baseline     when verify fails, rerun it on the base commit and
                        pass if no failures are new
  --verify VERIFY       acceptance command run on the host in the worktree
                        after the executor finishes; its exit code overrides a
                        sandbox-limited partial/done
  --auto-rework [N]     on host verify failure, dispatch up to N automatic
                        reworks (default 2 when the flag has no value), each
                        with the fresh failure evidence injected, re-verifying
                        after each; when retries are exhausted, escalate once
                        to a stronger backend tier (#95)
  --verify-evalid       verify with evalid: replay the executor's claimed test
                        command in a clean clone via `xflow audit` and record
                        the claim-vs-replay verdict in the ledger (#99);
                        requires --verify; fails loudly when evalid is
                        unavailable, never falls back to plain verify
  --evalid-bin EVALID_BIN
                        evalid binary: path to xflow, or to a bin/xflow.js
                        checkout (run via node); overrides EVALID_BIN, xflow
                        on PATH, and the sibling ../evalid checkout
  --keep-worktree
  --no-fallback
  --budget-minutes BUDGET_MINUTES
                        hard wall-clock budget; executor is killed when
                        exceeded
  --detach              run in background; monitor with `openswarm watch <id>`
  --dry-run
  --health-gate         enable the pre-dispatch backend health gate for this
                        run (M24, #198): probe the selected backend before
                        dispatch and refuse when it is unhealthy
  --no-health-gate      disable the pre-dispatch backend health gate for this
                        run even when routing.health_gate.enabled is true
  --skip-health-gate    bypass the health gate for this run; the bypass is
                        recorded in the ledger and result.json (M24, #198)
  --read-only           review task: allow status=done without repo changes or
                        commits
  --executor EXECUTOR   optional GitHub bus executor routing label
